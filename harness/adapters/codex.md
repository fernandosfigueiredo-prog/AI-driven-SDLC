# Adaptador operacional — Codex

- Entrada do projeto: AGENTS.md. Arquivos adicionais de harness precisam ser lidos conforme o roteamento; não são carregados magicamente por estarem no repo.
- Respeite instruções do ambiente e as instruções locais aplicáveis. Não suponha que um CODEX.md seja entrada automática.
- Use a capacidade de planejamento disponível ou instrução explícita “planeje sem implementar”.
- Ferramentas de plano/tarefas da sessão são auxiliares; não substituem Issues e checkpoints compartilhados.
- Subagentes, autenticação GitHub e hooks não são presumidos. Quando ausentes, usar operação manual autorizada, sem simular recursos.
- Limites textuais não equivalem a maxTurns imposto pelo runtime. Registrar métrica observável conforme budgets.md.
- Persistir checkpoint antes de transferência; retomar pelo workflow de handoff.

Referência oficial: https://developers.openai.com/codex/guides/agents-md
