# Roteamento por capacidade, risco e custo

Claude Code é o runtime primário; Codex opcional. Papel, modelo e runtime não são a mesma coisa.
Verificar modelos efetivamente disponíveis; usar aliases quando suportados, sem depender de versão específica.

- EM Buddy: conversa principal; usuário seleciona na GUI modelo competente/de ponta. Plugin não altera automaticamente o modelo da UI.
- Discovery e arquitetura difícil: modelo forte (preferir opus disponível); entrevista ocorre na sessão principal.
- Engenharia previsível: modelo eficiente sem sacrificar qualidade. Aumentar capacidade ao encontrar complexidade material.
- Revisão L3: contexto independente; preferir modelo/sessão diferente do autor quando acessível.
- Sínteses: reutilizar evidências, sem repetir investigação cara.

Por fatia registrar role, runtime, model efetivo (ou desconhecido), effort, risk, complexity, budget, fallback.
Codex sem mecanismo real de execução: gerar checkpoint recuperável, não fingir delegação. Escalar capacidade por hipótese diagnóstica nova, risco ou falha persistente.
