# Handoff — snapshot atual, não apêndice infinito

Criar checkpoint apenas em troca real de runtime, sessão interrompida ou WIP difícil de reconstruir.
Manter snapshot editável: Issue/spec/aprovação, branch/HEAD/diff, decisões válidas, escopo, dependências, realizado/pendente, testes realmente executados, falhas para não repetir, orçamento e próxima ação.
Git/PR/Issues guardam histórico. Nenhum novo arquivo ou PR obrigatório a cada rodada autor-revisor. Na retomada, reconciliar branch e evidências; não reiniciar orçamento ou autorizações.
