# GitHub Projects — organização opcional

A Issue é a fonte de verdade da fatia; o Project é somente uma visualização. Não criar um segundo plano com requisitos conflitantes.

Board enxuto: Discovery → Ready → In Progress → Review → Done. Campo Blocked/risco pode representar impedimentos sem multiplicar colunas.
Campos úteis: Initiative, Risk L0–L3, Complexity S/M/L/XL, Harness efetivo, Maturity POC/MVP/produção. Usar apenas os que simplificarem acompanhamento.

A criação/edição de Project depende de permissões e ferramentas GitHub Projects realmente disponíveis; este plugin não provisiona automaticamente os Projects, nem afirma sincronização onde não há integração.
Ao fechar Issue, anexar PR e breve relatório final; não copiar cada log do agente. Para stakeholders, sintetizar valor, evidência, risco e próximo marco a partir dos itens reais.
