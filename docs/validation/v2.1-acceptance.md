## Roteiro no painel do VS Code (testes 3 e 4)

Cerca de 10 minutos, no sandbox `C:\workspace\sdlc-sandbox`, que tem o plugin habilitado só nele (escopo local).

1. Abra a pasta no VS Code e inicie uma conversa nova no painel do Claude Code.
2. Pergunte "qual é o seu papel nesta sessão?". Esperado: EM Buddy.
3. Digite `/sdlc:` e confira os sete comandos no menu.
4. Envie `/sdlc:discover Quero que o financeiro consiga conciliar os pedidos do mês com o extrato do banco e ver o que não bate.` e responda pelo menos duas rodadas, usando o formulário de opções quando ele aparecer.
5. Diga "volta pro EM: onde estamos?". Esperado: resposta iniciada por **[EM]** com as suas decisões; o arquivo `docs/specs/<slug>/spec.md` contém as mesmas decisões.
6. Feche a conversa, abra outra e pergunte "onde estamos?". Esperado: retomada pelo `.sdlc/state.md`.

Para cada passo, registre ok ou falhou e uma observação. O resultado entra nesta tabela somente depois da validação.
